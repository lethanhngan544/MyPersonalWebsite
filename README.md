# Two Sides — Portfolio Starter

A responsive, two-panel portfolio starter built with plain HTML and CSS. The light panel is for embedded software engineering; the dark panel is for game programming and furry work. It has no build step or package dependencies and is ready to publish from the repository root with GitHub Pages.

## Customize

Edit the headings and descriptions in `index.html`, then replace or add images in `pics/`. Image paths are relative to the repository root; preserve filename capitalization when referencing them.

## Publish with GitHub Pages

1. Create a GitHub repository and push these files to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and the **/(root)** folder, then save.
5. Wait for the Pages deployment to finish. GitHub will show the published website URL in the Pages settings.

The homepage is `index.html` at the repository root, which works for both project sites and user sites. No local server is required; open `index.html` in a browser to preview it.
